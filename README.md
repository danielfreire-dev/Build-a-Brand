# Build-a-Brand

A senior-designer-level brand design engagement that creates a brand identity tailored to your business — never copied from other brands. Covers touchpoints, style, and audience (B2B, B2C, B2M, M2M/MCP), then distinct directions, mockups (landing page, business card, slides), and a complete Brand Style Brief with design tokens.

---

## What It Is

The **build-a-brand** skill runs a complete brand design engagement the way a senior designer would — through structured interview rounds, distinct creative directions, real mockups on your actual touchpoints, and a final Brand Style Brief with design tokens. It creates a brand that will _only_ belong to you, not a remix of competitors or category defaults.

---

## How It Works: The 5-Stage Arc

| Stage             | What Happens                                                                                                             |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **1. Interview**  | Rounds of 3–5 targeted questions until strategy is clear (touchpoints, audience, brand truths, personality, constraints) |
| **2. Directions** | Three genuinely different concepts, each built from _your_ brand's own material — not borrowed looks                     |
| **3. Refine**     | Lock the building blocks of the chosen direction (logo, color, type, shape, motion, voice)                               |
| **4. Reveal**     | Mockups on your priority touchpoints (landing page, business card, slides, etc.) built from one token system             |
| **5. Brief**      | Complete Brand Style Brief with tokens, rationale, do/don't rules, and next steps                                        |

---

## How to Use It

**Just start a conversation.** Say something like:

> "I want to build a brand for my [business/project]. It's a [one-sentence description]. Can we start?"

The skill will:

1. **Open with Q1–Q3** — where the brand lives, your gut style, and who the audience is
2. **Run interview rounds** — each with numbered questions, options, _Why it matters_, and a specific recommendation so you can just say "yes" or push back
3. **Present three directions** — Rooted, The Zag, The Wildcard — with a comparison table
4. **Refine your choice** — lock every visual/verbal element
5. **Show mockups** — on the touchpoints you starred in Q1
6. **Deliver the Brief** — a complete, developer-ready specification

**Pace controls:** Say **"speed up"** to skip to load-bearing questions, or **"go deeper"** on any branch.

## Key Benefits & Value

| Benefit                             | What It Means for You                                                                                                                                                                       |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Truly unique, not derivative**    | Every choice traces to _your_ origin story, product, name, or process — not a competitor's look                                                                                             |
| **Designer-level rigor**            | Uses methods from Vignelli (discipline), Rand (idea in the mark), Scher (serious play), plus Bierut, Neumeier, Haviv, Rams, Hara, Aicher, Kare, Bringhurst, Norman, Bass, Tufte, Anne/Frost |
| **Built for your real touchpoints** | A brand that lives on embroidered uniforms gets a different mark than one in an MCP directory — the hardest touchpoint drives the system                                                    |
| **Expression budget**               | Spends boldness where it counts (packaging, launch moments) and stays quiet where people see it daily (dashboards, receipts)                                                                |
| **No generic AI look**              | Actively avoids purple gradients, Inter everywhere, centered hero + 3 cards, "unlock the power of" copy, pulsing glows                                                                      |
| **Developer-ready output**          | Design tokens (CSS custom properties), contrast-checked colors, licensed font specs, motion values, accessibility defaults                                                                  |
| **Decision log throughout**         | Locked / open / assumed tracked every 2–3 rounds — no drift, no silent assumptions                                                                                                          |
| **Swap test built in**              | Every direction is checked: if a competitor's name fits, it goes back to the drawing board                                                                                                  |

## What Makes It Different from DIY or Template Approaches

| Typical DIY / Template            | Build-a-Brand                                                                                  |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| Picks colors from a trend palette | Samples palette from your materials, place, product                                            |
| Chooses "modern, clean" fonts     | Selects type for voice, touchpoints, scripts — with distinctive, less-overused starting points |
| Logo = icon + name                | Logo built from name's letters, product shape, or a mark from the making process               |
| Mockups = placeholder content     | Real copy in your voice, on your actual touchpoints, at true proportion                        |
| One "final" PDF                   | Tokens + Brief + mockups + next steps (templates, dev handoff, trademark flag)                 |
